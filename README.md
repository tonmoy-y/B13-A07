# KeenKeeper

KeenKeeper is a friendship CRM that helps you keep track of the people who matter, their status, and your next touch point.

## Technologies Used

- Next.js 
- React
- Tailwind CSS
- DaisyUI
- Recharts
- React Toastify

## Key Features

- Friend directory with profile pages, tags, and contact cadence details
- Quick check-ins (call, text, video) that log activity to a timeline
- Simple analytics dashboard to visualize interaction counts
